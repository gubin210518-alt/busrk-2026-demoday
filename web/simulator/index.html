예측은 PC 프로그램 안의 현재 모델로 계산합니다.

시뮬레이션 설정

시뮬레이션은 가정한 계수로 만든 가상 상자예요. 실제 측정이 아니에요.

ESP32 메시지

실험 기록

학습이름종류길이시작 온도가장 낮은 온도목표 도달

ESP32를 연결하면 기록이 자동으로 쌓이고, 새 딸기를 시작하거나 ESP32가 다시 켜지면 새 실험으로 나뉩니다. 박스에 저장된 log.csv(시리얼 모니터에서 d 입력 후 복사)도 불러올 수 있어요. 기록은 이 브라우저에 저장됩니다.

학습 설정

λ(릿지 규제): 가중치가 지나치게 커지지 않게 눌러 주는 값이에요. 기록이 적을수록 조금 키우면(예: 5) 안정적이고, 0이면 일반 선형 회귀예요. 보통 1 그대로 두면 됩니다.
체크한 실험 중 5개마다 1개는 시험용으로 빼 두고, 나머지로 학습합니다. 시험용 실험에서 목표에 실제로 닿은 시각과 예측을 비교합니다.

이 AI는 무엇을 배우나

입력 4가지: 식품칸−냉기실 온도 차, 냉기실 온도, 식품칸이 최근 2분 동안 식은 속도, 냉기실이 최근 2분 동안 변한 속도.
출력 2가지: 2분 뒤 식품칸 온도 변화, 2분 뒤 냉기실 온도 변화 (선형 회귀, 릿지 규제).
예측할 때는 이 모델을 2분씩 반복해서 목표 온도에 닿는 시각을 찾습니다. 아이스팩이 녹아 냉기가 약해지는 것, 딸기 덩어리가 공기보다 늦게 식는 것을 기록에서 배울 수 있어요.

학습된 가중치

표준화한 입력 기준 가중치예요. 절댓값이 클수록 그 입력이 예측에 크게 작용합니다.

model.h 


  
    
    
  1. precool_ai.ino(또는 precool_ai_demo.ino, 블루투스판 precool_ai_ble.ino)를 열고, 코드 안 "학습 모델 (model.h)" 블록의 MODEL_READY부터 MODEL_WC까지를 위 내용으로 바꿉니다.
    2. 
    
  2. Arduino IDE에서 precool_ai.ino를 열고 보드를 "ESP32 Dev Module"로 고른 뒤 업로드합니다.
    3. 
    
  3. 시리얼 모니터(115200)에 m을 입력하거나, 이 프로그램의 "모델 확인"을 누르면 들어간 모델 정보가 나옵니다.
    4. 
  







  

    
처음 한 번
    
      
  1. 크롬이나 엣지로 이 파일을 엽니다. (ESP32 연결은 이 두 브라우저에서만 돼요)
    2. 
      
  2. precool_ai.ino(대회 시연은 precool_ai_demo.ino, 휴대폰 앱으로 볼 때는 precool_ai_ble.ino)를 ESP32에 업로드합니다. 코드는 소스코드 페이지에서 받아요.
    3. 
      
  3. 업로드가 끝나면 Arduino 시리얼 모니터를 닫습니다. (포트를 한 프로그램만 쓸 수 있어요)
    4. 
      
  4. "ESP32 연결"을 누르고 포트를 고릅니다. 10초마다 온도가 들어옵니다.
    5. 
    

    
AI를 실제 기록으로 다시 학습하기
    
      
  1. 실온 딸기를 넣고 팬이 켜진 상태로 실험을 여러 번 합니다. 회차마다 "새 딸기 시작"을 누릅니다.
    2. 
      
  2. "실험 기록"에서 실측 기록만 체크합니다. (가상 실험은 빼기)
    3. 
      
  3. "AI 학습"에서 학습하기 → 오차 비교 확인 → "이 모델을 사용하기".
    4. 
      
  4. "펌웨어로 보내기"에서 model.h를 받아 다시 업로드합니다.
    5. 
    

    
하드웨어 없이 보여 줄 때
"시뮬레이션 시작"을 누르면 가상 상자가 빠르게 식는 모습과 AI 예측 경로가 그래프에 나옵니다. "뚜껑 열기"로 뚜껑을 열었을 때 냉각이 멈추는 것도 볼 수 있어요. 가상 상자의 계수는 가정한 값이므로, 발표에서 실측 결과처럼 말하면 안 됩니다.
