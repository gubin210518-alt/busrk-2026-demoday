연결 전에 확인할 것

  1. 선을 꽂거나 뺄 때는 USB를 먼저 빼요. 켜진 상태에서 5V 선이 GPIO나 3V3 단자에 닿으면 보드가 망가질 수 있어요.
  2. 선 색은 상품마다 다를 수 있어요. DS18B20과 서보의 선 색은 상세 페이지 설명과 실물을 먼저 봐요.
  3. 서보와 팬이 같이 돌 때 보드가 재부팅되면 5V 2A 어댑터를 따로 써서 5V 묶음에 넣고, 어댑터 GND를 GND 묶음에 함께 묶어요.
  4. 보드의 D2, D5, D12, D15는 쓰지 않았어요. BOOT 버튼의 GPIO0과 함께 부팅 방식에 영향을 주는 핀이에요. RX0·TX0도 업로드에 쓰여서 비워 둬요.
  5. 보드에 인쇄된 이름과 코드 번호는 같은 핀이에요. 보드의 D4가 코드의 GPIO4(코드에서는 4)예요.
  6. 꼬아 묶은 전원선은 헐거우면 접촉 불량이 나요. 가닥을 단단히 꼬고 열수축 튜브로 끝까지 덮어요. 가능하면 꼰 부분을 납땜하면 더 튼튼해요. 단자 나사를 조인 뒤 한 가닥씩 살짝 당겨 보고, 전원을 켜기 전에 멀티미터로 3.3V·5V·GND 묶음끼리 쇼트가 없는지 확인해요.
  7. OLED와 MOSFET 모듈은 납땜이 필요할 수 있어요. 핀이나 단자가 따로 오는지 받아서 확인해요.
  8. MOSFET 모듈은 판매 페이지 기준 전원이 최소 6V예요. 5V에서는 팬이 약하게 돌거나 안 돌 수 있어요. 팬 시험 코드로 먼저 확인해요.
