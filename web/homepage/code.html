소스코드

ESP32에 올리는 아두이노 코드예요. 부품 점검 코드로 배선을 확인한 다음, AI가 들어간 전체 동작 코드를 올려요. 전체 코드는 파일 하나로 되어 있어서 그대로 열어 업로드하면 돼요.

먼저 준비

  • 아두이노 IDE에서 보드 매니저로 esp32(Espressif)를 설치하고, 보드는 ESP32 Dev Module을 골라요.
  • 라이브러리 매니저에서 설치: OneWire, DallasTemperature, ESP32Servo, Adafruit SSD1306, Adafruit GFX Library
  • 업로드가 안 되면 업로드 중에 보드의 BOOT 버튼을 누르고 있어요.
  • 시리얼 모니터는 115200으로 맞춰요.

0. 부품 점검 코드 (실내용)

부품을 하나씩 켜 보고 결과를 시리얼 모니터와 OLED에 보여 줘요. 켜면 전체 점검을 한 번 하고, 그다음엔 두 센서 온도와 리드스위치 값을 2초마다 보여 줘요.

  • 시리얼 모니터에 숫자를 보내면 그 부품만 다시 점검해요: 1 온도센서, 2 LED, 3 부저, 4 서보, 5 팬, 6 리드스위치, 0 전체
  • 센서 하나를 손으로 쥐면 그 센서 온도만 올라가요. 식품칸용, 냉기실용을 이렇게 구분해요.
  • 부저와 리드스위치는 LOW일 때와 HIGH일 때를 보여 줘요. 그 결과로 전체 동작 코드의 설정을 정해요.

0-2. 반복 동작 시험 코드 (실내용)

LED, 서보, 팬, 부저를 계속 껐다 켰다 하고, OLED에는 두 온도센서의 온도와 상태(OK, ERR, NONE), 뚜껑 상태를 보여 줘요.

  • LED는 1초마다 빨강, 노랑, 초록 차례로 바뀌어요.
  • 서보는 2초마다 0도와 90도를 오가요.
  • 팬은 3초 켜고 3초 꺼요.
  • 부저는 2초마다 짧게 울려요. 시끄러우면 코드 위쪽 BUZZER_ENABLE을 false로 바꿔요.

1. 팬 시험 코드

팬을 5초 켜고 5초 끄기를 반복해요. 팬이 힘차게 돌면 MOSFET 연결이 맞은 거예요.

MOSFET 모듈연결
초록 단자 PWMD19 단자
초록 단자 GNDGND 묶음
파란 단자 +5V 묶음 (VIN 단자)
파란 단자 LOAD (가운데)팬 검정
파란 단자 −GND 묶음
팬 빨강파란 단자 + (5V 선과 같은 칸)
1N5819팬 빨강~검정 사이, 띠가 빨강(+) 쪽

파란 단자 표시(+ / LOAD / −)는 같은 모양 모듈의 판매 페이지 기준이에요. 보드 뒷면 글자와 맞는지 먼저 확인해요. 이 모듈은 판매 페이지 기준 전원이 최소 6V라서, 5V에서는 팬이 약하게 돌거나 안 돌 수 있어요.

2. 예냉박스 AI 전체 동작 코드

  • 시작: 딸기를 넣고 전원을 켜면 그 순간을 "수확 후 0분"으로 보고 시간을 세요. 새 딸기를 넣을 때는 시리얼 모니터에 r을 보내거나 AI 시뮬레이터의 "새 딸기 시작"을 눌러요.
  • 인지: 2초마다 식품칸과 냉기실 공기 온도를 읽고, 리드스위치로 뚜껑을 봐요.
  • 판단 (AI): 학습 모델이 지금 온도와 최근 2분 기울기로 2분 뒤 온도 변화를 예측하고, 이를 반복해 목표 온도(1℃)까지 남은 시간을 계산해요. 모델 숫자는 코드 안 "학습 모델 (model.h)" 블록에 들어 있어요.
  • 판단 (계산식): 뉴턴 냉각 법칙으로도 함께 계산해요. 처음 2분과 냉기실 센서를 못 읽을 때는 이 값으로 판단해요.
  • 행동: 넣자마자 댐퍼를 열고 팬을 켜요. 목표에 닿으면 멈추고, 1.5℃를 넘게 다시 데워지면 다시 켜요. 식품칸이 0℃ 아래로 내려가면 얼지 않게 팬을 꺼요. 뚜껑이 열려 있으면 팬을 멈추고, 30초 넘게 열려 있으면 부저가 울려요.
  • 표시: 노랑은 식히는 중이고 1시간 안에 될 것 같다는 뜻, 빨강은 1시간 안에 어렵다는 예측(10초마다 삑) 또는 1시간이 지났다는 뜻(2초마다 삑), 초록은 목표 도달이에요. OLED에는 "ETA 12m AI"처럼 남은 시간과 예측 방법이 나와요.
  • 기록: 30초마다 보드 안에 log.csv로 저장하고(d 출력, x 삭제), 10초마다 AI 시뮬레이터로 데이터를 보내요. m을 보내면 들어 있는 모델 정보가 나와요.

목표 1℃와 "수확 후 1시간"은 딸기 냉각 안내 자료를 따랐어요. 실험 후 TARGET_C 값을 바꿀 수 있어요.

3. 시연 모드 코드 (발표·영상용)

실제 기준(1℃, 60분)은 발표 시간 안에 결과를 보여 주기 어려워서 만든 버전이에요. 목표 15℃, 제한 10분으로 바꾸고 OLED 아래에 DEMO15/10m이 표시돼요. 나머지 동작과 AI는 전체 동작 코드와 같아요.

  • 목표 온도는 시작할 때 식품칸 온도보다 5~8℃ 낮게 잡아요. 코드 위쪽 DEMO_TARGET_C에서 바꿔요.
  • AI 시뮬레이터에 연결하면 목표 온도와 제한 시간이 자동으로 맞춰져요.

4. AI 시뮬레이터 (PC 프로그램)

크롬이나 엣지에서 열어요. ESP32를 USB로 연결하면 온도 그래프와 AI 예측 경로, 뉴턴 계산식과 AI의 남은 시간이 실시간으로 나와요. 하드웨어 없이 가상 상자로 돌려 볼 수도 있고, 모은 기록으로 AI를 다시 학습해 새 model.h를 만들 수 있어요.

AI 시뮬레이터 열기

처음 켰을 때 맞출 것

  • 온도센서 주소: 센서를 하나만 꽂고 켜면 시리얼에 주소가 찍혀요. 식품칸용, 냉기실용을 각각 확인해서 코드 위쪽 ADDR_BERRY, ADDR_COLD에 넣어요.
  • 뚜껑: 자석을 대고 떼면서 시리얼의 lid=OPEN/CLOSED가 맞는지 봐요. 반대면 LID_CLOSED_LEVEL을 HIGH로 바꿔요.
  • 부저: 켜자마자 계속 울리면 BUZZER_ON_LEVEL을 HIGH로 바꿔요.
  • 댐퍼 각도: 실제 상자에 맞게 DAMPER_CLOSED_DEG, DAMPER_OPEN_DEG를 조정해요.
  • OLED: 화면이 안 나오면 코드의 0x3C를 0x3D로 바꿔 봐요. OLED에는 한글 글꼴이 없어서 영어로 표시돼요.
