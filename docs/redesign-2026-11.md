# 예냉박스 재디자인 (2026-11-14)

## 왜
기존 포스터·홈페이지·시뮬레이터가 흔한 템플릿처럼 보임(회색 배경, 파란 버튼, 똑같은 카드 반복).
본선 심사에서 "이 팀만의 것"으로 기억되게 만드는 것이 목표.

## 핵심 아이디어: 식는 곡선이 주인공
이 프로젝트의 본질은 "수확 직후 25℃ 딸기를 1시간 안에 1℃까지 식히는 것".
그래서 모든 결과물의 대표 요소는 25℃에서 1℃로 떨어지는 냉각 곡선과 60분 골든타임 선이다.
나머지는 조용하게 둔다.

## 색
| 이름 | 값 | 쓰임 |
|---|---|---|
| 서리 | #EAF2F5 | 바탕 |
| 얼음 | #CFE2EA | 선, 칸 구분, 옅은 면 |
| 심해 | #0F2A3A | 글자, 진한 면 |
| 딸기 | #D7263D | 열·시간·강조(한 곳에만) |
| 잎 | #1E6B4B | 완료·초록 신호 |
| 경고 | #E8A400 | 노랑 신호 |

신호등 3색은 실제 제품의 LED 의미(완료/식히는 중/늦을 위험)로만 쓴다.

## 글꼴
- 제목: Hahmlet (굵은 한글 세리프, 크게 써서 표지처럼)
- 본문·숫자: Pretendard (숫자는 고정폭 숫자)

## 배치
- 왼쪽 정렬, 비대칭. 첫 화면은 큰 제목 + 그 아래 가로로 꽉 찬 냉각 곡선.
- 카드 남발 금지. 구분은 얇은 얼음색 선과 여백으로.
- 대문자 라벨, "A · B · C" 메타 줄, 버튼 끝 화살표 쓰지 않음.
- 움직임은 첫 화면 곡선이 한 번 그려지는 것 하나만(모션 줄이기 설정 존중).
